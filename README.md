# مطبعة كروت الشبكة

تطبيق ويب عربي RTL لاستيراد بيانات بطاقات الشبكة وتصميمها ومعاينتها وتصديرها إلى PDF.

## التشغيل
افتح `index.html` في متصفح حديث. يتطلب الاتصال بالإنترنت لتحميل مكتبات SheetJS وjsPDF وhtml2canvas من CDN.

## المزايا
- استيراد XLSX وXLS وCSV.
- ربط أعمدة الملف باسم المستخدم وكلمة المرور والسعر والصلاحية.
- تحميل صورة خلفية للكرت وتخصيص الألوان والشفافية.
- التحكم بأبعاد الكرت، الأعمدة، المسافات، الخط، والزوايا.
- معاينة أول صفحة وتصدير جميع السجلات إلى PDF متعدد الصفحات.
- يرسم تصدير PDF كل كرت من HTML/CSS الفعلي المستخدم في المعاينة؛ لذلك تظهر الخلفيات والألوان والنصوص العربية وفق تشكيل المتصفح، بدلاً من إعادة رسم النص بخطوط PDF الافتراضية.
- مؤشر تقدم أثناء تجهيز PDF، مع التحقق من عدم تجاوز عرض الكروت لعرض الورقة.
- تتم معالجة البيانات محلياً داخل المتصفح؛ لا يتم رفع ملف البيانات إلى خادم.

## ملاحظات وحدود
- يتم إدراج الكروت في PDF كصور PNG عالية الدقة (مقياس 2.5x)، وليس كنص PDF قابل للبحث أو النسخ؛ وهذا يحافظ على شكل النص العربي والخلفية، لكنه قد يزيد حجم الملف.
- يعتمد إدراج صور الخلفية على كونها محمّلة محلياً من الملف المختار. الصور الخارجية قد تخضع لقيود CORS في المتصفح.
- المكتبات والخطوط التي يستخدمها المتصفح تتطلب الاتصال بمصادر CDN.
