# مطبعة كروت الشبكة

تطبيق ويب عربي RTL لاستيراد بيانات بطاقات الشبكة وتصميمها ومعاينتها وتصديرها PDF.

## التشغيل
افتح `index.html` في متصفح حديث. يتطلب الاتصال بالإنترنت لتحميل مكتبات SheetJS وjsPDF من CDN.

## المزايا
- استيراد XLSX وXLS وCSV.
- ربط أعمدة الملف باسم المستخدم وكلمة المرور والسعر والصلاحية.
- تحميل صورة خلفية وتخصيص الألوان والشفافية.
- التحكم بأبعاد الكرت، الأعمدة، المسافات، الخط، والزوايا.
- معاينة أول صفحة وتصدير جميع السجلات إلى PDF متعدد الصفحات.
- المعالجة محلياً داخل المتصفح؛ لا يتم رفع الملف إلى خادم.

## ملاحظة
تصدير PDF الحالي يطبع النصوص والحدود والألوان؛ صورة الخلفية المرفوعة تظهر في المعاينة، وسيتم تضمينها في مرحلة تحسين التصدير القادمة.
